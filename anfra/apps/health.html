Issues opened and median first response

  • Core team: anyone who merged a pull request in the repo, or whom GitHub shows as an owner, member or collaborator. Everyone else is community. Bots (GitHub Apps and automation accounts) are left out.
  • First response: hours from a community issue being opened to the first comment by the core team, read from the issue's first 10 comments. Issues with no such reply count in "Issues answered", not in the median.
  • Community PR share: merged pull requests opened by the community, out of all merged pull requests not opened by bots.
  • Only issues and pull requests opened in the last 365 days count. Stars are today's count.

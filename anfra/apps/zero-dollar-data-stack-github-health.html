How it's measured
  • Core team: anyone who merged a pull request, or whom GitHub shows as an owner, member or collaborator. Bots are left out.
  • First response: time from a community issue to the first core-team comment, within its first 10 comments.
  • Community PRs: merged pull requests from the community, out of all merged pull requests not from bots.
  • Only issues and pull requests opened in the last 365 days count. Stars are today's count.
